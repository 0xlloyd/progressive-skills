# Flow modules

Common steps to add to the spine when the research shows the task needs them.
This is a menu, not a closed list: add any step the research shows experts rely on, and leave out any module that wouldn't change the output.

| Module | Typical tasks | What it adds |
|---|---|---|
| References and inspiration | Marketing, design, content, anything visual | Examples of excellent work to aim at before making anything |
| Audience and message | Copy, comms, decks, positioning | One clear message for a named reader, set before writing |
| Copy pass | Any prose that will be published or sent | Tightening, plus a check for generic AI-sounding phrasing |
| Visual direction | Decks, posters, landing pages, images | Style, palette and layout agreed before production |
| Shot list or storyboard | Video, image series | Every frame planned so generation or filming isn't guesswork |
| Variants, then select [GATE] | Images, headlines, names, concepts | Several options so the user picks rather than accepts the first |
| Data gathering and analysis in code | Anything with numbers | Figures computed, not estimated in prose |
| Options analysis [GATE] | Strategy, prioritisation, commercial trade-offs | Options with trade-offs laid out for the user to choose |
| Criteria and costings | Business cases, funding decisions | Each item tested against explicit criteria, with costs |
| Quality rubric | When the bar matters more than speed | Criteria for best in class, used to judge the output |
| Unit-by-unit build [GATE] | Decks or documents the user wants to co-build | One section at a time, approved before the next |
| Stakeholder rehearsal or pre-mortem | Senior, customer-facing or contentious work | Objections and failure modes found before the real audience does |
| Independent review | High-stakes outputs | A fresh reviewer who didn't make the work checks it |
| Packaging and distribution | Anything shared onward | Versions for each channel, such as an email summary or one-pager |
